# 智能运营平台功能说明

## 智能体配置中心

网页进入“配置中心”，可为六个领域智能体设置显示名称、数据源模式、真实接口 Base URL、认证请求头和工具到接口的 JSON 映射。认证值只写入本机配置，不通过查询接口回传。配置修改仅允许本机访问。

接口映射示例：

```json
{
  "query_iot_terminals": {"path": "/device/terminal", "method": "POST"},
  "query_iot_beacons": {"path": "/device/terminal/beacon/list", "method": "GET"}
}
```

## 模拟/真实接口切换

- `mock`：继续调用现有场景模拟数据。
- `real`：调用配置的真实 Base URL 和工具接口映射。
- 真实模式没有映射时返回明确错误，不回退模拟数据。
- 数据源配置在每次工具调用时读取，保存后无需重启服务。

## 演示导演模式

内置医疗绿通、人员安全、楼宇消防、养老照护、设备诊断和物联网围栏六套剧本。支持启动、下一步、重置，以及将当前步骤直接发送给对应智能体。

## 轨迹回放与热力图

六个领域均提供演示轨迹，网页以动画路径、时间节点和热力范围展示。接口为：

`GET /api/visualizations/{scene}/trajectory?keyword=对象名称`

## 一键生成报告

网页选择当前智能体后生成 HTML 运营报告，报告页可以直接打印或保存为 PDF。报告只调用当前场景的独立工具集。

## 智能体总控

网页和 Telegram 均可选择“智能体总控”。总控根据业务词识别目标领域，再转交对应智能体；实际业务工具仍在目标场景白名单内执行。

路由检查接口：`GET /api/router?question=用户问题`
