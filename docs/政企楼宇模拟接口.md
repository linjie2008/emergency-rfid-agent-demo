# 政企楼宇模拟接口

数据模型依据《长隆项目-综合监控与可视化管理系统-系统接口 V1.2》中的 19 个子系统调研项构造，所有数据均为演示模拟数据。

## 场景隔离

- 医疗：`medical`，仅加载患者绿通与医疗资产工具。
- 人员安全：`safety`，仅加载园区人员、作业票、考勤、能源与预测维护工具。
- 政企楼宇：`building`，仅加载本文件所列楼宇工具。
- 聊天请求必须带 `scene`；服务端会再次把场景写入会话 ID，并使用独立的工具白名单与内存。

## 公共场景接口

- `GET /api/scenes`：场景清单。
- `GET /api/scenes/{scene}/tools`：指定场景允许调用的工具。
- `POST /api/scenes/{scene}/tools/{tool_name}`：调用指定场景工具，请求体为 `{"args": {...}}`。工具不属于该场景时返回 404。
- `POST /api/chat`：对话，请求体增加 `scene=medical|safety|building`。

## 三场景统一定位接口

以下接口在 `medical`、`safety`、`building` 三个场景中名称、参数和返回结构一致，但由场景白名单路由到各自独立的数据集：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/scenes/{scene}/positioning/persons/realtime` | 人员实时位置；支持 `keyword`、`region`、`person_type` |
| GET | `/api/scenes/{scene}/positioning/persons/history?person=...` | 单人历史轨迹 |
| GET | `/api/scenes/{scene}/positioning/persons/region-events?person=...` | 人员区域进出 |
| GET | `/api/scenes/{scene}/positioning/assets/realtime` | 资产实时位置；支持 `keyword`、`region`、`asset_type` |
| GET | `/api/scenes/{scene}/positioning/assets/history?asset=...` | 单资产历史轨迹 |
| GET | `/api/scenes/{scene}/positioning/assets/region-events?asset=...` | 资产区域进出 |

对应的智能体工具名分别为 `query_locations_realtime`、`query_locations_history`、`query_region_enter_leave`、`query_asset_locations_realtime`、`query_asset_locations_history`、`query_asset_region_enter_leave`。

## 政企楼宇 REST 接口

| 方法 | 路径 | 数据范围 |
| --- | --- | --- |
| GET | `/api/scenes/building/overview` | 综合运营态势 |
| GET | `/api/scenes/building/power` | 电压、电流、功率因数、谐波与楼层负载 |
| GET | `/api/scenes/building/energy?days=7` | 分项能耗、PUE、EUI 趋势 |
| GET | `/api/scenes/building/hvac` | 空调、水温、负载与 EER |
| GET | `/api/scenes/building/water` | 给排水液位、压力、流量与水泵 |
| GET | `/api/scenes/building/lighting` | 楼层照度、回路、感应与调光 |
| GET | `/api/scenes/building/solar` | 光伏容量、功率与发电量 |
| GET | `/api/scenes/building/charging-piles` | 充电桩状态、电量、营收与温度 |
| GET | `/api/scenes/building/data-room` | 机房环境、UPS、存储与网络设备 |
| GET | `/api/scenes/building/parking` | 停车分区与空余车位 |
| GET | `/api/scenes/building/elevators` | 20 部电梯实时状态与里程 |
| GET | `/api/scenes/building/security` | 门禁、巡更与访客 |
| GET | `/api/scenes/building/fire-linkage` | 消防与空调/新风联动 |
| GET | `/api/scenes/building/alarms` | 跨系统告警及处理状态 |
| GET | `/api/scenes/building/assets` | 独立楼宇资产台账 |
| GET | `/api/scenes/building/maintenance` | 维护计划与到期状态 |
| GET | `/api/scenes/building/emergency/{alarm_id}` | 告警定位与演示应急流程 |

各查询接口支持与字段同名的筛选参数，例如 `floor=9F`、`status=异常`、`system=消防联动`。
