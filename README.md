# 多场景智能运营中心 Demo

同一个演示入口支持切换六个数据与接口相互隔离的智能体：

- 医疗智能体：急诊绿通患者、轨迹、超时和医疗资产定位/能效。
- 人员安全智能体：人员定位、作业票、考勤门禁、能源运营与预测性维护。
- 政企楼宇智能体：依据长隆项目调研清单模拟的电力、空调、给排水、照明、光伏、充电桩、机房、停车、电梯、安防、消防、资产和应急接口。
- 智慧养老智能体：依据《钛颐康智慧养老物联网平台API》模拟老人、床位、健康终端、区域围栏与养老告警接口。
- 设备诊断智能体：依据《STD-设备状态监测与故障诊断软件接口文档V1.6》模拟设备树、实时/历史指标、报警、波形频谱和诊断建议接口。
- 物联网平台智能体：依据《真趣物联网平台接口文档 V2.9》模拟建筑、终端、信标、电子围栏、历史轨迹、物模型与事件订阅接口。

前端切换场景时，服务端使用独立的业务工具白名单、数据模块、会话 ID 和记忆空间；六者仅共用不携带业务数据的表格、图表、回复格式和原理图渲染能力。政企楼宇 REST 接口见 [docs/政企楼宇模拟接口.md](docs/政企楼宇模拟接口.md)，新增领域说明见 [docs/新增三领域智能体模拟接口.md](docs/新增三领域智能体模拟接口.md)。

平台还提供智能体总控与六项运营能力：本机配置中心、模拟/真实接口切换、演示导演模式、轨迹回放与热力图、一键生成可打印报告，以及按意图自动路由的智能体总控。真实模式只有在配置了工具接口映射后才会访问客户系统，缺少映射时会明确报错，不会把模拟数据伪装为真实数据。配置和报告保存在本机 `runtime/` 目录，公网访客不能修改配置或启动演示。

三个场景都提供统一的人与资产定位接口，包括实时位置、历史轨迹和区域进出；接口契约一致，数据按 `medical`、`safety`、`building` 场景命名空间隔离。

面向能源企业交流展示的 LangGraph 智能体，覆盖人员安全、承包商、定位轨迹、作业票合规、报警、考勤门禁，以及电、热、气一体化运营分析。

## 能力范围

- 人员与组织：员工、部门、承包商、访客、人员目录树
- 时空定位：实时位置、历史轨迹、区域进出、在线人数
- 作业安全：作业票、合规率、违规规则、流程时长、报警与质检
- 劳动管理：考勤排班、门禁、承包商工时、异常驻留、疲劳风险
- 电力生产：机组出力、热负荷、煤耗、可用率、电网负荷
- 输变配电：变电站、线路负载、温升、计划/故障停电
- 供热燃气：温压流、热网报警、供气量、门站压力与加臭状态
- 能源调度：调度指令、经营能耗、安全风险、电热气综合驾驶舱
- 预测性维护：监测终端、设备健康度、状态趋势、故障概率、剩余寿命与检修建议

当前提供 60 个可调用 Skill，使用本地模拟数据。接真实系统时可保持工具入参与返回结构，替换工具内部的数据源。

### 预测性维护 REST 接口

- `GET /api/predictive-maintenance/terminals`：监测终端明细
- `GET /api/predictive-maintenance/terminals/summary`：终端在线率与数据质量
- `GET /api/predictive-maintenance/health`：设备健康度
- `GET /api/predictive-maintenance/condition`：单设备监测趋势
- `GET /api/predictive-maintenance/predictions`：故障风险预测
- `GET /api/predictive-maintenance/rul`：剩余可用寿命
- `GET /api/predictive-maintenance/maintenance-plan`：维护计划建议
- `GET /api/predictive-maintenance/summary`：预测性维护驾驶舱汇总

## 一键运行

```bash
cd /home/administrator/emergency-rfid-agent-demo
./manage.sh start
./manage.sh status
./manage.sh stop
```

网页地址为 `http://127.0.0.1:7861`。如果 `.env` 配置了 `TELEGRAM_BOT_TOKEN`，启动脚本会同时启动 Telegram Bot。

本地 `Qwen3.8-27B` 默认不常驻：选择本地模型并首次发送问题时自动加载；空闲 300 秒后自动停止并释放 GPU/内存。可在 `.env` 用 `LOCAL_MODEL_IDLE_TIMEOUT` 调整时间，页面顶部也可以手动启动或释放。

每次启动本地模型前，管理器会先终止本项目遗留的同权重 `llama-server`，在 ComfyUI 队列为空时调用 `/free` 卸载图像/视频模型，并回收服务进程堆内存；若 ComfyUI 正在执行任务则拒绝抢占显存，待任务完成后再启动。该流程不会结束其他无关程序。

本地模型使用动态工具路由：先识别人员、定位、作业票、能源、预测性维护等业务域，再只向模型加载相关接口。全部 60 个业务接口均可访问，但不会同时占用上下文；无明确业务关键词的追问会沿用当前会话上一次路由。

## 手动启动

```bash
cd /home/administrator/emergency-rfid-agent-demo
source .venv/bin/activate
```

在 `.env` 配置 `DEEPSEEK_API_KEY` 或 `OPENAI_API_KEY` 后：

```bash
python app.py
```

访问 `http://服务器地址:7861`。未配置模型密钥时，页面和 Skill 测试仍可启动，但对话功能会提示配置密钥。
